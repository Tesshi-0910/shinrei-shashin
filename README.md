# 心霊写真マップ

全国の「写ってしまった」写真を地図に投稿・共有するサイトです。
Render（Web Service＋PostgreSQL）だけで動きます。

## 構成
- `server.js` … Express サーバー（API・写真配信・管理者機能）
- `public/index.html` … サイト本体
- `render.yaml` … Render の Blueprint（サーバーとデータベースを一括作成）

## 管理者
- サイトのURLの最後に `#admin` を付けて開き、環境変数 `ADMIN_PASSWORD` のパスワードでログインします。
- 通報された投稿の確認・非表示・削除ができます。3人から通報された投稿は自動で非表示になります。

## 注意（無料プラン）
- 15分アクセスがないとサーバーが停止し、次の表示に1分ほどかかります。
- 無料の PostgreSQL は作成から30日で使えなくなり、その14日後にデータが削除されます。続けて使う場合は有料プランに切り替えてください。
